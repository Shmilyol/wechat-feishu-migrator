# 微信收藏表情迁移到飞书

将微信收藏表情下载为图片，**每组最多 50 张**，再分批添加到飞书个人表情中。支持下载续跑、图片去重和添加进度记录，保留原始 GIF 动画文件。

基本流程：**导出微信收藏 → 查看编号文件夹 → 先添加一张 → 每批最多 50 张继续添加。**

[Windows 上手](#windows-上手) · [下载与分组问题](#下载与分组问题) · [自动添加](#自动添加实验性) · [macOS 使用](#macos-使用) · [常见问题](#常见问题)

> [!IMPORTANT]
> 微信导出、本地分组和飞书添加是三个步骤。**导出成功不代表已经添加到飞书。** 推荐先手动试一张，确认能正常发送后再批量添加；自动添加仍属于实验功能。

## 支持情况

| 功能 | Windows | macOS |
| --- | --- | --- |
| 自动读取微信收藏 | 支持尝试读取 64 位微信 4.1+（4.x），包含 x64、ARM64 | 需提供本机已有的数据库密钥文件 |
| 本地图片分组 | 支持，每组最多 50 张 | 支持，每组最多 50 张 |
| 手动按批添加到飞书 | 支持，由用户选择图片并确认 | 支持，由用户选择图片并确认 |
| 桌面自动添加 | 实验性，每批最多 50 张 | 实验性，逐张添加 |

**已有实机反馈：**Windows 原生 ARM64、Python 3.13.17、微信 4.2.0.9，已完成 570 条收藏记录读取、绝大多数图片下载及本地分组；少量记录因没有原图地址或服务器返回 404 而未获取。该结果不代表所有微信版本或设备均兼容，飞书自动添加尚未完成同等实机验证。

## Windows 上手

### 1. 下载项目并安装依赖

准备以下环境：

- Windows 10 / 11。
- [Python 3.10 或以上版本](https://www.python.org/downloads/windows/)，必须是 **64 位**。ARM64 设备可使用 ARM64 Python，普通 x64 电脑使用 x64 Python。
- 已安装并登录的 64 位微信；添加表情时还需登录飞书桌面客户端。
- 能访问微信图片资源的网络连接。

在仓库页面选择 **代码（Code）→ 下载 ZIP（Download ZIP）**，解压后进入包含 `migrate.py` 的文件夹。也可以使用 Git 克隆本仓库。

在文件资源管理器的地址栏输入 `powershell` 并按回车，打开项目目录的终端。**下面所有 Windows 命令都在这个目录执行**，不要在上一级文件夹运行。

确认 Python 可用：

```powershell
py -3 --version
```

创建虚拟环境：

```powershell
py -3 -m venv .venv
```

安装依赖：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

看到 `Successfully installed` 表示安装完成。后续直接调用虚拟环境中的解释器，无需激活环境或修改 PowerShell 执行策略。

### 2. 检测微信账号

保持微信运行并登录，在微信中打开一次**收藏表情面板**，再执行：

```powershell
.\.venv\Scripts\python.exe .\migrate.py --probe
```

正常时会显示微信版本、运行进程和账号数据库位置。显示多个微信进程是正常现象，**进程数量不等于账号数量**。此命令只做检测，不读取数据库密钥。

<details>
<summary>没有找到账号，或发现多个账号</summary>

在微信设置中查看数据保存位置，找到 `xwechat_files` 文件夹。参数需要的是这个根目录，不是里面的账号文件夹。

先列出账号，将示例路径替换为实际路径：

```powershell
.\.venv\Scripts\python.exe .\migrate.py --list-accounts --wechat-data-dir "D:\微信数据\xwechat_files"
```

多个账号时，将输出中的完整账号目录名传给 `--wxid`，与数据目录一起用于下一步导出：

```powershell
.\.venv\Scripts\python.exe .\migrate.py --export --wechat-data-dir "D:\微信数据\xwechat_files" --wxid "实际账号目录名"
```

</details>

### 3. 导出图片并查看分组

只有一个账号且检测正常时，执行：

```powershell
.\.venv\Scripts\python.exe .\migrate.py --export
```

程序会先读取收藏记录，再检查已有下载、下载缺少的图片，最后生成分组。**保持当前终端运行即可，不需要另开一个终端重复执行。**

运行中的常见提示：

| 提示 | 含义 |
| --- | --- |
| `读取到 570 个收藏记录` | 已读取收藏列表，接下来才开始处理图片 |
| `缓存检查 10/570` | 正在核对已有下载记录，不代表 570 张都已下载成功 |
| `[3/570] 已缓存，复用本地图片` | 这一条已有可用图片，无需重新下载 |
| `请求资源 2/10` | 当前表情正在尝试第 2 个候选地址，不是第 2 张图片 |
| `完成……进度已保存` | 当前图片已下载，续跑时可以复用 |
| `分组完成` | 本地编号文件夹已经生成，可以开始添加到飞书 |

默认最多 4 张图片同时下载，所以终端序号可能交错。网络较慢时会重试并显示等待提示。

打开分组结果：

```powershell
explorer.exe "$HOME\WeChat-Feishu-Stickers\exported"
```

**结果保存在用户主目录，不在项目源码目录中。**例如，123 个图片文件会整理为：

```text
exported/
├── 1/    # 50 张
├── 2/    # 50 张
└── 3/    # 23 张
```

> [!NOTE]
> 收藏记录数、图片文件数和飞书新增数量可能不同。同一图片可能出现在多条收藏记录中；缺少地址、资源失效或飞书不接受的图片，也不能计入成功迁移数量。

即使只有少数图片下载失败，**成功图片也会完成分组**。程序仍会报错，表示这次导出不完整；你可以先添加已有图片，无需等所有失败项恢复。具体处理见[下载与分组问题](#下载与分组问题)。

### 4. 先试一张，再分批添加到飞书

先在飞书桌面端打开个人表情添加入口，通常位于聊天窗口的“表情 → 添加的单个表情”中，实际位置以客户端为准。

推荐使用手动模式：**你负责在飞书点击添加、选择图片并提交；脚本负责准备本批图片和记录结果，不会代替你上传。**不需要校准坐标。

首次只试一张：

```powershell
.\.venv\Scripts\python.exe .\migrate.py --import --manual-import
```

运行后按以下顺序操作：

1. **准备飞书。**打开任意聊天，点击输入框旁的表情按钮，找到个人/收藏表情中的「+ 添加」。不要把图片作为普通消息发送。
2. **回终端按回车。**脚本会打开一个只含本批图片的临时文件夹，并打印它的完整路径。首次试用时里面只有 `001.png` 或 `001.gif` 等一张图片；这时还没有上传。
3. **复制终端中的目录路径。**切回飞书，点击「+ 添加」，让飞书打开选择图片窗口。
4. **在飞书的选择图片窗口中**按 `Ctrl+L`，粘贴刚才的目录路径，按回车进入该文件夹。
5. 按 `Ctrl+A` 选中本批图片，点击「打开」。如果还有预览或确认页面，再点「添加/确认」，等待完成。
6. 到飞书个人表情列表核查图片已经出现，首次试用还应测试能否发送。然后回终端输入 `y` 并按回车，保存成功记录。

> [!NOTE]
> 弹出的文件资源管理器只是供查看。真正添加图片的操作发生在**飞书打开的文件选择窗口**中。如果窗口里的图片不是本批的 `001`、`002`……，先确认进入了脚本本次打印的目录。

确认效果后，按每批最多 50 张继续（程序结束时也会打印这条命令）：

```powershell
.\.venv\Scripts\python.exe .\migrate.py --import --manual-import --yes --batch-size 50
```

每批都按终端列出的文件名选择，完成后返回终端确认：

| 输入 | 处理结果 |
| --- | --- |
| `y` | 本批全部成功，保存记录并继续下一批 |
| `1,3` | 只确认本批列表中的第 1、3 张，保存后暂停 |
| `n` 或直接回车 | 不确认成功，保存尝试记录并暂停 |

**只在脚本本次准备的临时选择目录中全选。**该目录只含本批图片，名称从 `001` 开始，与终端确认序号对应；本批确认结束后会清理。原始图片和 `exported/1`、`2`……正式分组保留。不要改到正式分组目录直接全选，否则可能重复添加已经处理过的图片。

终端会分别显示本地文件数、重复内容、已人工确认、曾尝试未确认和本次实际处理数量。例如 567 个文件只有 564 张待处理，差额可能来自这些跳过项，按各项统计判断；不是图片丢失。

已经人工确认成功的图片会跳过。添加失败或中断后，先核查飞书，再重试已尝试但未确认的图片：

```powershell
.\.venv\Scripts\python.exe .\migrate.py --import --manual-import --yes --retry-attempted
```

未确认不代表一定失败；如果图片实际上已添加，重复提交可能产生重复收藏。不要只因为脚本完成操作就输入 `y`。

## 下载与分组问题

### 只有几张失败，其他图片能先用吗？

**可以。**当前版本会把成功下载的图片分组，同时保留失败记录。失败详情中：

- `no candidate URLs`：该收藏没有提取到可用原图地址，反复重跑通常无法解决。
- `HTTP 404`：尝试的地址没有返回该资源，可能已经失效，程序不能保证恢复。
- 网络、证书或超时错误：按后面的[常见问题](#常见问题)处理，再重试失败项。

保留现有缓存，先导入已经分组的图片即可。`--all` 在部分下载失败时会停止，不会自动开始飞书操作；需要单独运行 `--import`。

### 已下载很多图片，但没有看到编号文件夹

下载中途停止、使用旧版本，或分组步骤未执行时，可以直接整理现有缓存：

```powershell
.\.venv\Scripts\python.exe .\migrate.py --group-only
```

再打开结果：

```powershell
explorer.exe "$HOME\WeChat-Feishu-Stickers\exported"
```

`--group-only` **不重新下载，也不读取微信**。可重复执行，已有分组会保留，新增图片继续追加。

### 下载很慢或暂时没有变化

先看终端是否正在重试或校验缓存。默认单次网络超时为 10 秒，每张图片的多个地址与重试共享 60 秒网络预算；系统网络调用或图片校验可能使实际耗时更长，这不是严格的倒计时。

需要停止时，在当前终端按 `Ctrl+C`，等待命令结束。已下载并保存记录的图片会保留。之后执行相同的 `--export` 命令即可续跑，也可以先用 `--group-only` 整理已有图片。

**不要同时运行多个导出任务，也不要删除缓存来重试。**

## 自动添加（实验性）

如果希望脚本代替手动选择文件，可以使用自动模式。它依赖飞书的窗口位置、按钮坐标和标准文件选择器，客户端更新、缩放变化或自定义弹窗可能使它失效。

先在飞书打开个人表情添加界面，再运行校准：

```powershell
.\.venv\Scripts\python.exe .\migrate.py --calibrate
```

回终端按回车后，有 **3 秒**把鼠标移到「+ 添加」按钮中心，**不要点击**。之后保持飞书窗口位置、主显示器和缩放比例不变。Lark 使用 `--calibrate --app-name Lark`。

先尝试一张：

```powershell
.\.venv\Scripts\python.exe .\migrate.py --import
```

核查效果后再批量运行：

```powershell
.\.venv\Scripts\python.exe .\migrate.py --import --yes --batch-size 50
```

每批结束仍需回终端输入 `y`、成功序号或 `n`；确认规则与手动模式相同。终端与飞书应以相同权限运行。

自动模式重试未确认图片：

```powershell
.\.venv\Scripts\python.exe .\migrate.py --import --yes --retry-attempted
```

自动操作期间可按 `Ctrl+C`，或将鼠标移到主屏左上角触发中止。若点击位置不正确、无法激活窗口或提示不是标准文件选择器，停止自动模式，改用 `--manual-import`。

## 已有本地图片，不需要读取微信

将图片放入用户主目录下的 `WeChat-Feishu-Stickers/exported` **根目录**。Windows 通常为：

```text
C:\Users\用户名\WeChat-Feishu-Stickers\exported
```

执行分组：

```powershell
py -3 .\migrate.py --group-only
```

只分组使用 Python 标准库，无需安装第三方依赖。分组后可在飞书中手动添加；如果还要使用脚本引导添加，则按前面的步骤安装依赖。

支持整理 `.gif`、`.png`、`.jpg`、`.jpeg`、`.webp`、`.bmp`、`.apng`。分组按文件扩展名识别，并不保证飞书接受全部格式、大小或保留动画效果。

## macOS 使用

macOS 支持本地分组、手动按批添加和逐张自动添加。**目前没有自动获取微信数据库密钥的能力**；没有已有密钥文件时，可直接处理本地图片。

只分组已有图片：

```bash
python3 migrate.py --group-only
```

需要下载或使用脚本引导添加时，在项目目录创建环境并安装依赖：

```bash
python3 -m venv .venv
```

```bash
./.venv/bin/python3 -m pip install -r requirements.txt
```

首次手动添加一张：

```bash
./.venv/bin/python3 migrate.py --import --manual-import
```

确认成功后按批继续：

```bash
./.venv/bin/python3 migrate.py --import --manual-import --yes
```

如果已有本机数据库密钥，可使用 UTF-8 文本文件导出，文件中仅填写 64 位十六进制字符：

```bash
./.venv/bin/python3 migrate.py --export --key-file "/本机私有目录/emoticon-key.txt"
```

自定义数据位置或多个账号同样可用 `--wechat-data-dir` 和 `--wxid`。

<details>
<summary>macOS 逐张自动添加</summary>

在系统设置“隐私与安全性 → 辅助功能”中，允许实际运行脚本的终端或编辑器控制电脑。打开飞书个人表情添加界面后校准：

```bash
./.venv/bin/python3 migrate.py --calibrate
```

再试一张：

```bash
./.venv/bin/python3 migrate.py --import
```

macOS 自动模式逐张选择，每张完成后都需核查。跨系统复制的校准坐标不能使用，需在当前电脑重新校准。

</details>

## 常见问题

| 问题或提示 | 怎么处理 |
| --- | --- |
| 找不到 `py` 或 `.venv` 中的解释器 | 确认安装了 64 位 Python、位于包含 `migrate.py` 的目录，并已创建本机虚拟环境；不要复制其他电脑的 `.venv` |
| 没有发现账号或表情数据库 | 登录微信并打开收藏面板；用 `--wechat-data-dir` 指定 `xwechat_files` 根目录 |
| 无法确定唯一账号 | 用 `--list-accounts` 查看，再用 `--wxid` 指定完整账号目录名 |
| 找不到通过验证的密钥 | 检查微信是否运行并登录、是否打开过收藏面板；保留实际版本、架构和扫描统计用于反馈，不要发送密钥 |
| 数据库或 WAL 校验失败 | 暂停新增、删除收藏，等待微信完成写入后重试；不要修改数据库 |
| `tls_certificate`，且 `verify_code=62` | 服务器证书与请求域名不匹配。先确认使用当前完整版本，再反馈日志中的目标域名；重复重试同一地址通常无效 |
| `dns` | 图片服务器或代理地址解析失败，检查网络和 DNS |
| `connection_refused` | 连接被拒绝，检查网络及正在使用的代理服务是否可用 |
| `timeout/connect` 或 `timeout/read` | 连接或接收超时；成功图片会保留，网络恢复后可续跑 |
| 提示导出不完整，但已有分组 | 仍有缺失记录；可以先添加已有图片，不必清空目录重新开始 |
| 收藏数与图片数不同 | 可能有重复图片、缺失地址或下载失败；以分组输出和最终确认结果为准 |
| 自动添加失败 | 停止后重新校准，或改用手动模式；已尝试的图片需核查后配合 `--retry-attempted` 重试 |
| macOS 无法读取微信数据 | 在系统设置检查实际终端或编辑器的文件访问权限 |

反馈问题时提供**系统与架构、微信和飞书版本、执行命令、第一条具体报错及其目标域名**即可。无需粘贴几百行重复重试，也不要发送数据库、密钥、完整资源链接或下载清单。

## 数据保存在什么位置

所有图片和进度保存在用户主目录的 `WeChat-Feishu-Stickers` 中，**更新项目代码不会要求清空这些数据**。

```text
WeChat-Feishu-Stickers/
├── exported/               # 1、2、3……编号分组，每组最多 50 张
├── .wxemoticon-cache/       # 原始图片缓存，沿用历史目录名
├── download_manifest.json  # 每条收藏的下载状态
├── source_order.json       # 本轮成功图片的收藏顺序
├── group_manifest.json     # 稳定分组映射
├── import-batches/          # 手动添加的临时选择目录，本批确认后清理
├── config.json             # 当前系统的按钮位置与等待时间
└── state.json              # 已尝试、已人工确认的飞书添加记录
```

Windows 通常为 `C:\Users\用户名\WeChat-Feishu-Stickers`，macOS 为 `~/WeChat-Feishu-Stickers`。

保留缓存和清单才能继续任务。分组优先使用硬链接，不支持时复制；直接修改分组图片可能同时改变缓存内容。

本工具读取本机微信收藏数据，下载时访问微信图片资源，不要求输入微信或飞书账号密码。自动获取的数据库密钥不写入日志或进度文件；下载清单含账号来源和资源链接，不宜随意分享。

## 命令速查

下表只列参数组合，前面需加上对应系统的 Python 解释器。Windows 为 `.\.venv\Scripts\python.exe .\migrate.py`，macOS 为 `./.venv/bin/python3 migrate.py`。

| 参数 | 用途 |
| --- | --- |
| `--probe` | 检测 Windows 微信版本和账号 |
| `--export` | 导出、下载并分组，复用已有成功记录 |
| `--group-only` | 只整理已有图片，不读取微信或下载 |
| `--import --manual-import` | 手动添加，默认只试一张 |
| `--import --manual-import --yes` | 手动按批继续，每批最多 50 张 |
| `--calibrate` | 校准自动模式的添加按钮 |
| `--import --yes --limit 10` | 自动模式本次最多尝试 10 张 |
| `--import --yes --retry-attempted` | 自动模式重试未人工确认的图片 |
| `--batch-size 20` | 每批最多 20 张，可设 1～50；macOS 自动模式仍逐张 |
| `--all` | 导出后继续添加；默认只试一张，自动模式需先校准；部分下载失败时停止 |
| `--pause-every 5` | 兼容旧参数，将批次进一步缩小为最多 5 张；每批仍需确认 |

查看全部参数：

```powershell
.\.venv\Scripts\python.exe .\migrate.py --help
```
